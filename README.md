# ImageInn-Radiology-System
Image Inn Radiology System is a C programming project developed to simulate a radiology clinic management system, incorporating admin login, employee record management, file handling, input validation, and structured programming concepts.

# Overview

A menu-driven radiology clinic management system developed in C programming.

> **Note:** This project was developed for educational purposes to demonstrate structured programming, file handling, and data management concepts in C programming.

# Features

- Admin authentication
- Employee management
- File handling
- Input validation
- Menu-driven navigation
- Structured data organization

# Technologies Used

- C Programming
- Structs
- Arrays
- Pointers
- File Handling

# Concepts Demonstrated

- Problem Solving
- Structured Programming
- Data Management
- User Input Validation

# How to Run

1. Compile the program using a C compiler

   ```bash
   gcc main.c -o radiologysystem
   ```

2. Run the executable
   ```bash
   ./radiologysystem
   ```
   
3. Follow the menu options displayed in the terminal
